📦 COMO CRIAR O EXECUTÁVEL:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Certifique-se de que Python está instalado

2. Dê DUPLO CLIQUE em "Criar_Executavel.bat"

3. Aguarde o processo (pode levar 3-5 minutos)

4. O executável será criado em: Distribuir\meu_Busca_Livros.exe


✅ O QUE O SCRIPT FAZ AUTOMATICAMENTE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Instala PyInstaller
✓ Verifica dependências
✓ Cria executável standalone (um único arquivo .exe)
✓ Inclui templates HTML e arquivos estáticos
✓ Cria pasta "Distribuir" com tudo necessário
✓ Gera documentação para o usuário final
✓ Limpa arquivos temporários
✓ Abre a pasta do executável

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🐛 TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"PyInstaller failed"
   → Tente: pip install --upgrade pyinstaller
   → Verifique se tem todas as dependências

"Missing module"
   → Adicione ao --hidden-import no Criar_Executavel.bat
   → Execute: pip install -r requirements.txt

"Templates not found"
   → Verifique se a pasta frontend/ existe
   → Verifique se app_exe.py tem os paths corretos

Executável muito grande (>100MB)
   → Normal para aplicações Flask completas
   → PyInstaller inclui todas as dependências


📝 NOTAS IMPORTANTES:

🔐 ASSINATURA DIGITAL (OPCIONAL):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Para evitar avisos de "Publisher Unknown":

1. Obtenha certificado de assinatura de código
2. Use SignTool.exe (Windows SDK)
3. Comando:
   signtool sign /f certificado.pfx /p senha meu_Busca_Livros.exe
