📚 meu_Busca_Livros

Buscador Universal de Livros Gratuitos

✨ Super Fácil de Usar!

Não precisa saber programar ou usar terminal. Apenas 2 cliques!

1 Instale o Python (apenas na primeira vez)

Se ainda não tem Python instalado:

  • Baixe de: python.org/downloads
  • IMPORTANTE: Durante a instalação, marque a opção "Add Python to PATH"
  • Clique em "Install Now"
2 Execute o programa

OPÇÃO A - Com janela minimizada (RECOMENDADO):

📄 Iniciar_Busca_Livros.bat

  • A janela será minimizada automaticamente após 2 segundos
  • Navegador abre automaticamente
  • Para parar: restaure a janela e pressione Ctrl+C

OPÇÃO B - Totalmente invisível (sem janela):

🔹 Iniciar_Invisivel.vbs

  • Servidor roda completamente em segundo plano
  • Nenhuma janela aparece
  • Para parar: duplo clique em Parar_Servidor.bat
3 Use a busca

Na página que abrir:

  1. Digite o nome do livro no campo de busca
  2. Opcionalmente, digite o autor
  3. Clique em "Buscar"
  4. Clique em "Baixar" no livro desejado
💡 Dica: Crie um atalho!

Dê duplo clique em Criar_Atalho_Desktop.bat para criar um atalho na sua área de trabalho.

🔧 Resolução de Problemas

❌ "Python não encontrado"

Você esqueceu de marcar "Add Python to PATH" durante a instalação.

Solução: Desinstale e reinstale o Python marcando essa opção.

⚠️ Navegador não abre

Abra manualmente no seu navegador: http://127.0.0.1:5000

ℹ️ Como parar o programa

Se usou Iniciar_Busca_Livros.bat:

  • Restaure a janela minimizada e pressione Ctrl+C
  • Ou feche a janela pela barra de tarefas

Se usou Iniciar_Invisivel.vbs:

  • Dê duplo clique em Parar_Servidor.bat
  • Ou abra o Gerenciador de Tarefas e finalize "python.exe"

📁 Onde ficam os downloads?

Os livros são salvos em: G:\Livros_Archive

Para mudar isso, edite a linha 22 do arquivo app_search.py
